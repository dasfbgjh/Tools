使用说明

  • 1. 选择图标类型：FontAwesome图标或自定义文字
  • 2. 配置图标内容、颜色、大小和旋转
  • 3. 选择背景形状和类型（纯色或渐变）
  • 4. 调整背景颜色或渐变设置
  • 5. 应用预设模板快速设计
  • 6. 选择导出尺寸和格式并下载
小贴士
  • 建议使用高对比度的颜色搭配，如黑底白图标或白底黑图标
  • 对于移动应用，推荐使用圆角正方形背景
  • 渐变背景可以让图标更有层次感和现代感
  • 自定义文字功能支持创建品牌首字母或简短词汇图标
  • 适当的旋转角度可以增加图标的动感
  • 新拟态和玻璃拟态模板适合现代UI设计
