支持的参数

            
    
                
  • 镜像 / 命令最后一个非参数位置为镜像，其后内容为容器命令 (command)
    • 
                
  • --name容器名称 container_name
    • 
                
  • -p / --publish端口映射，如 -p 8080:80
    • 
                
  • -e / --env环境变量，如 -e KEY=value
    • 
                
  • -v / --volume卷挂载，如 -v /host:/container
    • 
                
  • -d / --detach后台运行（compose 默认后台，仅记录标记）
    • 
                
  • --restart重启策略，如 always / unless-stopped / on-failure
    • 
                
  • --network / --net网络，会同时在顶层声明 networks
    • 
                
  • -w / --workdir工作目录 working_dir
    • 
                
  • -u / --user运行用户 user
    • 
                
  • --entrypoint入口点 entrypoint
    • 
                
  • --privileged特权模式 privileged: true
    • 
                
  • --cap-add添加 Linux 能力 cap_add
    • 
                
  • --dnsDNS 服务器 dns
    • 
                
  • --hostname容器主机名 hostname
    • 
                
  • -l / --label容器标签 labels
    • 
                
  • 忽略项-i / -t / -it（交互与 TTY，compose 不需要）
    • 
                
  • --rm运行后删除容器，compose 无直接对应，仅记录说明
