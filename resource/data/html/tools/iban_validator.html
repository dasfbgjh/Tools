校验算法说明

  • 1. 清理移除空格，转大写
  • 2. 重排将前 4 位（国家代码 + 校验位）移到末尾
  • 3. 转数字字母转为数字 (A=10, B=11, ..., Z=35)
  • 4. 校验对大数取 mod 97，结果为 1 即有效
