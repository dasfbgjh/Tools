支持键值对、嵌套、数组、引号字符串、数字/布尔、注释、多行字符串（| 与 >）。


                

                

                    

                        
                        
                    

                    

                

            

        


        

            
使用说明

            
    
                
  • 格式化解析后重新序列化为标准 2 空格缩进的 YAML
    • 
                
  • 转 JSON将 YAML 解析为 JavaScript 对象并以 JSON 形式展示
                
    • 
                
  • 压缩去除空行与注释，输出紧凑 YAML
    • 
                
  • 校验检查 YAML 语法并提示出错行号
    • 
                
  • 树形视图以可折叠/展开的树形结构展示数据，支持全部展开/折叠
    • 
                
  • 键名排序勾选后格式化时按键名字母顺序排序对象键
    • 
                
  • 多行字符串支持 | 保留换行 与 > 折叠换行，及 +/− 截断标记
    • 
                
  • 注意内置简化解析器，未使用外部库；复杂 YAML 特性可能不支持
    •
