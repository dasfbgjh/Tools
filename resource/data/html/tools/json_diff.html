原始 JSON，将作为对比基准

目标 JSON，与 A 进行深度对比

使用说明

  • 对比递归深度对比两个 JSON，支持嵌套对象与数组
  • 新增仅存在于 JSON B 中的键或数组元素（绿色）
  • 删除仅存在于 JSON A 中的键或数组元素（红色）
  • 修改两边都存在但值不同，显示 旧值 → 新值（黄色）
  • 类型不匹配字符串与数字等类型差异视为修改，并显示类型信息
  • 路径显示完整路径，如 users[0].name
  • 显示相同项勾选后同时展示值相同的字段
  • 交换将 JSON A 与 B 内容互换并重新对比
  • 格式化对两个输入框分别进行 2 空格美化
